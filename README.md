# Daily Praise

Daily Praise is a lightweight one-page web tool that gives users a small, sincere compliment when they need a little lift.

## Features

- Random compliment on page load
- Four praise styles: Warm, Professional, Funny, Emotionally Smart
- One-click refresh with lightweight animation
- Responsive desktop and mobile layout
- Analytics-ready events through `window.dataLayer`

## Local Preview

Open `index.html` directly in a browser.

## Analytics Events

The MVP currently emits:

- `page_view`
- `praise_impression`
- `praise_next_click`
- `praise_style_click`

See `analytics-plan.md` for the metric plan.
